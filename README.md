# PROGREE Task 2: Responsive Developer Portfolio Website

A state-of-the-art, high-performance, fully responsive personal developer portfolio web application built with HTML5, Vanilla CSS3 (Custom Design System & Glassmorphic UI), and Modern JavaScript (ES6+).

---

## 🌟 Key Features

1. **Responsive & Mobile-First Design**:
   - Optimized for all viewport sizes (Desktop, Tablet, Mobile) with fluid typography and dynamic CSS grid layouts.
   - Mobile navigation drawer with animated hamburger menu.

2. **Rich Dark & Light Mode Support**:
   - Built-in theme switcher with CSS variable mapping and `localStorage` persistence.
   - Respects system preferences (`prefers-color-scheme`).

3. **Dynamic & Interactive Elements**:
   - **Interactive Particle Canvas Background**: Live geometric particle animation connecting nearby nodes on HTML5 Canvas.
   - **Typewriter Effect**: Animated hero text dynamically cycling through developer specializations.
   - **Interactive Skill Progress Bars**: Animated skill proficiency meters with category filtering (Frontend, Backend, DevOps).
   - **Filterable Featured Projects**: Category tab filtering (Web Apps, AI & Cloud, FinTech) with instant UI state transitions.
   - **Interactive Project Modal**: Rich popup detail modal showcasing architecture, key features, and technology tags for each project.
   - **Animated Experience Timeline**: Interactive vertical timeline highlighting career progression and educational achievements.
   - **Testimonials Carousel**: Automated slider with manual control buttons and dot indicators.
   - **Client-Side Form Validation**: Real-time error feedback, regex email verification, and animated Toast alerts upon submission.

4. **SEO & Performance Optimization**:
   - OpenGraph meta tags, clean semantic HTML5, zero heavy framework overhead, fast rendering time.

## 🚀 How to Run Locally

1. Simply double-click `index.html` or open it in any modern Web Browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
2. Alternatively, serve using a lightweight static server like VS Code Live Server or Node `http-server`:
   ```bash
   npx http-server D:\PROGREE-B7-Full-Stack\Task-02-Responsive-Portfolio -p 8080
   ```
3. Visit `http://localhost:8080` in your web browser.
